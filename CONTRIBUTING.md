# Contributing

Cheat CLI is maintained by [Rejish J](https://github.com/RejishJ).

## Bug Reports

If you find a bug, please [open an issue](https://github.com/RejishJ/cheat-cli/issues) with:

- A clear description of the problem
- Steps to reproduce
- Your Python version and OS
- Any error output

## Feature Requests

Feature requests are welcome. Please open an issue describing what you'd like and why.

## Code Contributions

Code contributions require explicit written permission from the maintainer. Pull requests submitted without prior discussion may not be accepted.

If you'd like to contribute code, please open an issue first to discuss the change.

## Code Reuse

This project is not open source. Reuse, redistribution, or modification of the source code is not permitted without explicit written permission. See [COPYRIGHT.md](COPYRIGHT.md) for details.

## Development Setup

```bash
git clone https://github.com/RejishJ/cheat-cli.git
cd cheat-cli
pip install -e .
```

## Running Tests

```bash
pytest
```
